# Visuels du projet

[Accueil](../../README.md) › [Documentation](../README.md) › Visuels

Les images de ce dossier accompagnent la présentation du MCP sur GitHub.
Elles sont versionnées avec le dépôt afin que les liens relatifs restent
valides après déplacement du projet.

## Schéma de fonctionnement

![Du client IA aux nœuds de calcul](architecture.svg)

[architecture.svg](architecture.svg) représente les échanges entre le client
IA, le serveur MCP local, SSH et Slurm. Il aide à situer l’exécution des
calculs et relève de la licence MIT du projet.

## Bannière ROMEO

![Illustration historique du supercalculateur ROMEO](romeo-banner.png)

[romeo-banner.png](romeo-banner.png) est le visuel associé à l’
[article officiel du 21 novembre 2013](https://romeo.univ-reims.fr/18_actualites.html/149/Romeo_le_cinquieme_supercalculateur_le_plus_eco-efficace_du_monde.).
Source : Centre de Calcul Régional ROMEO / URCA. Il illustre le calculateur
présenté en 2013. Les droits du visuel et des logos appartiennent à leurs
titulaires ; la licence du code ne leur est pas étendue.

## Réutilisation et mise à jour

Conserver un texte alternatif décrivant chaque image, des liens relatifs
depuis les pages et les [mentions des contenus tiers](../../THIRD_PARTY_NOTICES.md).
Les captures d’écran de la documentation officielle se trouvent dans un
[dossier distinct du corpus](../../romeo_mcp/documentation/images/README.md),
où leurs empreintes sont suivies par le manifeste documentaire.
