## Préparer une demande d’assistance

La page officielle d’assistance indique le canal à utiliser. Pour expliquer
un problème technique, conserver le nom de la ressource, la date, les étapes
effectuées et un exemple permettant de reproduire le comportement. Les outils
de diagnostic du MCP peuvent fournir des éléments sur les accès et les jobs.
Choisir les extraits nécessaires et retirer les informations sensibles avant
de les partager.

Ces pages documentent les services du centre. Les modalités et disponibilités
sont celles de la source officielle, à vérifier depuis le lien de chaque page.
