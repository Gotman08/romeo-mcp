## Conservation et attribution

Les suffixes des fichiers font partie des noms utilisés par les liens locaux.
Toute modification d’une image ou de son nom implique de revoir les pages
qui la référencent et son empreinte dans [manifest.json](../manifest.json).

Ces captures restent attribuées à leurs auteurs et titulaires de droits.
Les règles de réutilisation figurent dans les
[mentions des contenus tiers](https://github.com/Gotman08/romeo-mcp/blob/main/THIRD_PARTY_NOTICES.md).
Les visuels de présentation du MCP sont documentés dans le
[guide des visuels du projet](https://github.com/Gotman08/romeo-mcp/blob/main/docs/assets/README.md).
